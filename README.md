# E-Stamp PDF Generator (Pakistan)

E-Stamp PDF Generator is a standalone Python desktop application that generates 8.5 x 14 inch (Legal Size) e-stamp PDF documents with embedded Code128 barcode and QR code. The application provides a structured affidavit-style layout suitable for printing and administrative documentation.

This tool is designed for local, offline document generation. It does not connect to any external systems or government databases.

---

## Features

- Legal size PDF generation (8.5 x 14 inches)
- Code128 barcode generation
- QR code generation
- Structured e-stamp layout
- Scrollable form-based Tkinter GUI
- Automatic timestamp defaults
- Save-as dialog for PDF export
- Clear all fields functionality
- Offline operation

---

## Technology Stack

- Python 3.8+
- Tkinter (GUI)
- ReportLab (PDF generation)
- python-barcode (Code128 barcode)
- qrcode (QR code generation)
- Pillow (Image handling)
